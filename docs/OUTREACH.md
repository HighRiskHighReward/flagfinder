# Source outreach: permission emails

Status of each source and why it needs permission: `docs/SOURCE_ACCESS.md`. When a source says
yes, record who agreed, when, and the scope in that source's `permission_notes`, then enable it
(Admin → Sources). Replace `[Your name]`, `[Your email]` and `[Your phone]` before sending.

Every email makes the same promises, and the app enforces them: we list only public event
details (name, dates, city, divisions, fee); every listing links back to the source; we check
politely (at most daily); and we stop immediately if asked.
